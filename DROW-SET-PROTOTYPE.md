# Sepulchral Stalker: прототип штатной примерки в Dota 2

**Статус: проверка запуска и внешнего вида в игре ещё не завершена.** Наличие комплекта и штатных команд подтверждено по установленному клиенту. Успешное применение в локальной демке и работа отдельных эффектов пока не заявляются.

## Что делает прототип

Core Coach открывает штатную страницу тестирования **Sepulchral Stalker**, затем использует запуск деморежима Dota 2. Комплект выбирается по настоящим определениям предметов из текущей установленной игры. Это позволяет проверить возможность примерки с обработкой моделей, слотов и доступных эффектов самим движком.

Это **не inventory changer уровня Overplus**: предметы не добавляются в Steam-инвентарь, право владения не меняется, комплект не становится доступным для обычных матчей. Подмена файлов моделей также не выдаётся за изменение инвентаря. DLL-хуки, внедрение в процесс и подмена ответов сервера инвентаря не используются.

## Как попробовать

1. Полностью закрой Dota 2. Steam должен быть запущен и авторизован обычным способом.
2. Для чистой проверки отключи ранее применённые локальные замены в настройках Core Coach, если они включены: они могут мешать оценке штатной примерки. Отключение выполняется при закрытой игре.
3. В настройках Core Coach нажми кнопку прототипа примерки **Sepulchral Stalker**. Приложение должно открыть Dota 2, страницу комплекта и штатный запуск Demo. До завершения проверки этот сценарий считается экспериментальным.
4. Если страница появилась, а деморежим не запустился автоматически, используй её штатную кнопку **Опробовать** в русском интерфейсе, **Демо: …** в украинском или **Demo …** в английском. Смена стиля выполняется штатным переключателем страницы, если он доступен.
5. В демке проверь именно новые части Sepulchral Stalker, а также тело Arcana. Затем проверь способности: Frost Arrows, Gust и Multishot. Некоторые эффекты зависят от выбранного стиля, состояния героя и игровых событий; одного появления модели недостаточно для подтверждения всех эффектов.

Чтобы закончить примерку, выйди из деморежима. Примерка не закрепляет набор в инвентаре аккаунта.

## Какие предметы используются

Sepulchral Stalker — новый комплект для Drow Ranger с основой существующей Arcana **Dread Retribution**. В текущем каталоге игры его preview-набор содержит основу Arcana и семь новых носимых частей.

| ID | Предмет | Слот |
|---|---|---|
| `19090` | Dread Retribution | `hero_base`, тело и логика Arcana |
| `34588` | Sepulchral Stalker — Arms | `arms` |
| `34589` | Sepulchral Stalker — Back | `back` |
| `34590` | Sepulchral Stalker — Head | `head` |
| `34591` | Sepulchral Stalker — Legs | `legs` |
| `34592` | Sepulchral Stalker — Misc | `misc` |
| `34593` | Sepulchral Stalker — Shoulder | `shoulder` |
| `34594` | Sepulchral Stalker — Weapon | `weapon` |

ID полного bundle — **`34595`**, ключ preview-набора — **`sepulchral_stalker`**. В bundle также входит курсор `37158`; его применение отдельно от героя в этом прототипе не подтверждено.

Использование только семи новых частей без `19090` не эквивалентно полному preview-набору: Arcana имеет отдельное тело и собственные обработчики эффектов.

## Ручная проверка штатной страницы

При открытом главном меню Dota 2 можно проверить страницу через консоль:

```text
dota_show_test_item_set_page sepulchral_stalker
```

Альтернативная страница определения bundle:

```text
dota_show_test_item_def_page 34595
```

Эти команды найдены в текущем клиенте вместе с описаниями страниц тестирования. Их доступность в запущенной retail-сборке и переход из страницы в деморежим должны быть подтверждены отдельно. Если команда недоступна или не открывает страницу, не следует считать прототип работающим.

В декодированном текущем `panorama/layout/dashboard_page_item_testing.vxml_c` кнопка `DemoButton` вызывает событие `DOTAItemTestingStartDemo()`. Поэтому для проверки перехода **после открытия этой страницы** предусмотрен такой кандидат вызова:

```text
panorama_dispatch_event "DOTAItemTestingStartDemo()"
```

Имя и отсутствие аргументов подтверждены файлом интерфейса; выполнение через консоль ещё не считается проверенным. У общей кнопки Demo другой обработчик — `DOTADemoButtonClicked(false)`; `true` используется кнопкой возврата в уже запущенную демку. Для страницы тестирования набора используется её собственный обработчик.

`dota_create_item` предназначена для обычных игровых предметов вроде Rapier и не является командой выдачи косметики по ID определения.

## Подтверждённые данные и границы проверки

Из текущего `game/dota/pak01_dir.vpk` прочитаны `scripts/items/items_game.txt`, запись bundle `34595` и `item_sets/sepulchral_stalker`. В установленном клиенте найдены штатные события `DOTAItemTestingStartDemo`, `DOTADemoHeroSet`, `DOTADemoHeroItems` и команда `panorama_dispatch_event`. Само наличие имени события ещё не подтверждает доступность вызова, правильность его аргументов или успешную активацию набора.

В штатном `hero_demo` указано, что режим использует специальный C++ путь активации из интерфейса Dota 2; обычный custom game не получает эту возможность автоматически. Поэтому прототип следует пути штатной примерки, а не обещает универсальную функцию Lua для выдачи носимых предметов.

Источники: [поставляемый Valve скрипт hero_demo](https://raw.githubusercontent.com/SteamTracking/GameTracking-Dota2/master/game/dota_addons/hero_demo/scripts/vscripts/addon_game_mode.lua), [документация Valve с примером dota_create_item](https://developer.valvesoftware.com/w/index.php?title=Dota_2_Workshop_Tools%2FLevel_Design%2FCreating_A_Dota-Style_Map&uselang=en). Точные ID и команды дополнительно сверены с локально установленными файлами игры; они не взяты из старого скачанного набора.
