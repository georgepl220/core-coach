# Core Coach 0.9.5

- В настройках добавлен локальный внешний вид Drow Ranger: обычный комплект или Arcana Dread Retribution.
- Заменяются тело и семь частей стандартного комплекта, включая оружие. Способности, их специальные эффекты и HUD в этой версии остаются стандартными. Для замены нужно надеть стандартный комплект Drow.
- Модели берутся из установленной игры. Отдельный пакет содержит девять путей ресурсов; исходные архивы, таблица предметов и проверочные файлы Dota не изменяются.
- При английской озвучке включение временно выбирает русскую для загрузки пакета. Кнопка отключения возвращает прежнюю озвучку и сохраняет язык интерфейса и остальные настройки.
- Подготовка пакета выполняется в worker. Запись разрешена только при закрытой Dota; повторная проверка выполняется перед изменениями.
- Модуль отслеживает свой пакет, обнаруживает обновление игры и конфликт файлов. Отключение удаляет только принадлежащий ему неизменённый пакет. Прерванная установка восстанавливается по журналу.

Внешний вид подтверждён в клиенте и локальном демо на установленной версии Dota. Работа в обычном сетевом матче отдельно не проверялась. Содержимое арканы не добавляется в инвентарь аккаунта.
