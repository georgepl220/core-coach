# Core Coach 0.6.1

Состав линии выбирается прямо в оверлее: нажми портрет напарника или врага, выбери героя своей либо вражеской команды. «Выбрать состав» и Ctrl + Alt + L запускают последовательность из трёх нажатий. После сохранения возвращаются обычные советы; повторная горячая клавиша или крестик закрывают выбор.

Панель помещается в компактный оверлей 340 × 420; все пять противников видны без прокрутки. Расширенный размер 340 × 600 также поддерживается. Ручной состав синхронизируется с основным окном, отметки показывают ручной выбор. «Вернуть авто» сохраняет известные команды. При неполном составе можно открыть основной каталог.

Мышь принимается только над портретами, кнопкой выбора и открытой панелью. Остальная карточка пропускает клики в игру. Оверлей остаётся без фокуса при выборе; Ctrl + Alt + M сохраняет отдельный режим перемещения. Области мыши проверяются в координатах окна с учётом масштаба; другое окно приложения не может назначить их. Подсказка закрытия использует глобальную горячую клавишу, не перехватывая Escape игры.

Алгоритм автоопределения, частота захвата экрана и источники билдов не изменены.
