# Core Coach 0.9.3

- Период пар STRATZ подтверждается запросами на границах недель, а не предположением по номеру недели. Патч определяется только для подтверждённого интервала внутри версии каталога STRATZ. Время последнего учтённого матча остаётся неизвестным.
- Режим всех рейтингов явно запрашивает пять согласованных групп; STRATZ сам объединяет статистику. Не используется пустой специальный фильтр ALL и не предполагается состав выборки запроса без фильтра.
- Из дневной базы исключены периоды предыдущего патча и пересекающий обновление день. При отсутствии полной базы нового патча новые пары сохраняются; старый WR не подставляется.
- Выбранная позиция требует статистики позиции. Общая база не выдаётся за результат выбранной роли.
- Загрузка рейтингов выполняется последовательно, последний выбранный рейтинг ставится в очередь, ошибки API не скрываются. Изменение или удаление токена безопасно отменяет неподходящие запросы.
- Исходный WR пары без поправки на силу обоих героев не используется как контрпик или синергия. Старый подтверждённый период отклоняется независимо от неизвестной даты последнего матча.
- Офлайн-проверка расширена до 74 составов на пяти позициях; на одинаковых кандидатах сравнивается влияние врагов, союзников и база WR. Коэффициенты рабочей модели сохранены.

Проверка чувствительности не доказывает увеличение побед. Отчёт: `PICKER-VALIDATION-0.9.3.md`. Подготовка исторических данных: `DRAFT-EVALUATION.md`.
