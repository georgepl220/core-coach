# Core Coach 0.5.3

Исправлено преждевременное замедление чтения верхних портретов: интервал десять секунд включается после независимого подтверждения команд, а не после первого распознанного кадра.

Добавлен диагностический режим `--recognition-diagnostics`: он сохраняет до 24 коротких отчётов по GSI, состоянию захвата, числу предложенных и распознанных иконок, составу и причине ожидания. Учётные записи, токены и изображения в отчёт не попадают. Локальный диагностический endpoint работает только в этом режиме и требует токен GSI; его значение не выводится. Окно настройки при диагностическом запуске остаётся скрытым, чтобы не отнимать фокус у игры.

Это обновление позволяет проверить реальную причину отказа. Оно не объявляет проблему живого распознавания устранённой без наблюдений из активного матча.
