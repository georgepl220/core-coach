# Dota2-Vis test examples

Three unmodified held-out minimap images and YOLO labels from RicardoRCarvalho/dota2-vis.

Source: https://github.com/RicardoRCarvalho/dota2-vis/tree/main/YOLO/test
License: CC BY-NC-SA 4.0 (dataset README).
Authors: R. R. Carvalho, E. Oliveira, L. B. M. Kummer, E. C. Paraiso, R. Laroca.
Paper: Computer Vision for MOBA Analytics: A Dataset and Baseline for Visibility Analysis in Dota 2 (SBGames 2026).
Paper link: https://arxiv.org/abs/2606.26970

These examples are for checking what minimap observations look like; no trained weights are included or claimed.
The 21 classes in data.yaml refer to player colors/clones, not hero identities.
