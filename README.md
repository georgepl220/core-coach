# Core Coach · личный помощник для керри

**Версия 0.9.7:** прежняя функция подмены моделей и ландшафтов удалена из активного приложения. Inventory changer не реализован: программа не добавляет предметы в инвентарь Dota. Пикер сохраняет каталог 127 героев, позиции 1–5 и пять рекомендаций с WR позиции, причиной выбора и риском. См. [CHANGES-0.9.7.md](CHANGES-0.9.7.md).

Windows-оверлей использует GSI, видимые иконки миникарты и проверяемые правила. Полного понимания драки и скрытых позиций нет.

Для продолжения разработки другим ИИ или разработчиком начни с [HANDOFF.md](HANDOFF.md): там описаны установка из lockfile, архитектура, проверки и известные ограничения. Личные настройки и токены находятся вне Git.

## Запуск

Открой `release/Core Coach/Core Coach.exe`. Либо открой `Start-Coach.cmd` в исходном проекте: он запускает готовую сборку, а при её отсутствии — Electron из `node_modules`.

При первой упаковке Core Coach переносит существующие файлы `runtime` из `release/Wraith Coach/resources/app/runtime`, включая настройки, токен GSI и личный билд. Уже существующие файлы Core Coach имеют приоритет. Старый каталог остаётся на месте; одновременно запускай только одну версию. Папка исходников `wk-coach` и совместимое имя GSI-конфига сохранены.

1. В **Настройках → Установить GSI** выбери папку `dota 2 beta`, если игра не найдена автоматически.
2. Добавь `-gamestateintegration` в параметры запуска Dota 2 в Steam, сохранив остальные параметры. Перезапусти игру.
3. Используй **окно без рамки**, включи постоянное отображение иконок героев на миникарте. Укажи сторону миникарты в приложении; размер значка оставь **Авто**. Для поиска по полоскам здоровья миникарта не обязательна.
4. Во вкладке **Анализ экрана** проверь рамки миникарты и двух рядов по пять портретов. При необходимости выдели области мышью.

Деморежим показывает вымышленные данные; настоящий GSI отключает его. Импортированный скриншот проверяет распознавание, но не подтверждает живую линию.

## Косметика

В версии 0.9.7 удалены настройки старых VPK-подмен, их запуск и IPC-команды. Recovery helpers сохранены в исходниках для отслеживаемых установок, но приложение их больше не запускает. Новый inventory changer не реализован. Отдельный эксперимент с файлом локального кеша проверен в игре при отключённом координаторе: Arcana Drow Ranger не появилась как доступный предмет. Исходный кеш восстановлен с проверкой SHA-256; эксперимент не включён в приложение.

## Линия и стадии

Нажми **Выбрать состав** или конкретную карточку **Напарник / Соперник**. Окно покажет четыре других героя твоей команды либо пять противников из распознанного драфта. Нажатие на портрет сохраняет выбор; последовательный режим сам переходит к следующему участнику. Один противник не может занимать два слота. Если драфт неполный или ошибочный, раскрой **Полный каталог** и найди героя по имени. Ручные участники отмечаются галочкой и имеют приоритет над автоматическими наблюдениями. **Вернуть автоопределение** снимает только выбор участников линии, сохраняя составы команд.

В оверлее нажми маленький портрет участника либо **Выбрать состав**. Панель с портретами команды временно заменяет советы и закрывается после сохранения. **Ctrl + Alt + L** открывает последовательный выбор напарника и двух врагов; повторное нажатие закрывает панель. Оверлей принимает мышь только над кнопками и панелью выбора, пропуская клики в игру в остальных местах. Выбор не требует перевода фокуса с игры. Если команда ещё неизвестна, можно открыть основной каталог через кнопку настроек. **Вернуть авто** снимает ручные роли, сохраняя известные команды.

В активном матче профиль керри автоматически выбирается по GSI. Вне матча используй список **Герой для советов** для просмотра сборки и деморежима. Каждому герою соответствует свой набор покупок, навыков и правил; кеши источников и личные сборки разделены. Без GSI ручной матчап показывает условный план, а личные показатели и следующий навык ждут данных игры. Записанный порядок навыков можно смотреть и без GSI.

Отдельная карточка **Определение линии** убрана. Приложение наблюдает команды по верхним портретам, участников — по значкам рядом с полосками здоровья или на миникарте. Для поиска в игровой сцене выбранный WK должен быть подтверждён по нижней панели и присутствовать в кадре. Полный драфт сам по себе не определяет соперников линии.

Без свежего GSI, во время паузы и после 10:00 показываются **Видимые герои**: союзник и до двух соперников рядом с выбранным WK. Это текущие наблюдения, а не доказательство исходного состава линии или роли саппорта. При пропадании выбранного WK экранный режим перестаёт назначать участников. Свежие данные GSI о другом герое или режиме наблюдателя имеют приоритет. Без GSI доступны правила конкретного сочетания героев; здоровье, закупка, навыки к прокачке, нетворс и исход линии не подменяются данными скриншота.

Участники проверяются **по отдельности**: каждому нужны минимум три разных уверенных кадра и не менее 10 секунд между первым и последним в окне наблюдений 90 секунд. Два врага и союзник не обязаны появляться одновременно. Приложение учитывает повторное присутствие рядом с WK в коридоре боковой линии; неоднозначные иконки, иллюзии и несколько равных кандидатов требуют новых наблюдений. Для напарника дополнительно проверяется устойчивое преобладание над другими союзниками.

В оверлее есть три маленькие иконки: **напарник, враг 1 и враг 2**. Неизвестное место обозначено `?`, кандидат до подтверждения — приглушённой иконкой с `?`. Подтверждённый герой может сохраняться по предыдущим кадрам; подпись показывает, что это история, а не его текущая видимая позиция. После линии состав остаётся историческим наблюдением. Близкий союзник — вероятный напарник; его роль позиции 5 не доказана.

По умолчанию выбирать героев и исход вручную не нужно. Если распознавание ошиблось, раскрой **Исправить героев** и укажи двух соперников или напарника; ручная поправка имеет приоритет. **Вернуть автоопределение** убирает поправки. В режиме **Только GSI** состав по экрану не обновляется.

Пять стадий: подготовка, линия, после линии, середина и поздняя игра. Автоматические границы — начало матча, 10:00, 15:00, 30:00. После 8:00 возможен ранний переход при уровне 8+ и готовом основном предмете. Стадию можно выбрать вручную в верхнем списке.

Для каждой стадии показаны главное действие, применение навыков и дополнительный совет. Лайнинг учитывает механики подтверждённых соперников и союзника. План после линии использует автоматическую оценку собственного темпа:

- **Успешная линия**, **Тяжёлая линия** или **Ровный темп** — согласуются как минимум две независимые группы признаков: фарм, развитие уровня, новые смерти или несколько наблюдавшихся убийств.
- **Неоднозначная линия** — данных достаточно, но признаки не дают согласованного вывода.
- **Мало данных** — не хватает истории или независимых признаков. Подключение после линии не восстанавливает её по позднему фарму.

Нужны минимум **три свежие точки GSI за две минуты**. До 10:00 оценка предварительная; около 10-й минуты она фиксируется и не переписывается последующими смертями и фармом. Повтор одного пакета, изменение здоровья без движения игровых часов и пауза не увеличивают число наблюдений. Без свежей связи оценка не показывается. Один низкий CS или одно убийство не определяют исход.

Это оценка твоего темпа, а не сравнение с экономикой врагов: GSI не сообщает их нетворс и вклад саппорта. LH сравниваются с личной целью. Точный собственный нетворс может дополнить фарм только при достаточной свежей carry-выборке; примерный нетворс не используется для оценки линии, а CS и нетворс остаются одной группой признаков. При ошибке раскрой **Поправить оценку**; это необязательная коррекция. Новый матч сбрасывает состав, историю оценки и ручную стадию.

Нетворс, LH, денаи и GPM показаны в обзоре. Оценка нетворса по золоту и предметам отмечена `≈`; она не учитывает курьера и поглощённые улучшения. Цели 50/140/230 LH к 10/20/30 минуте — редактируемые личные ориентиры.

## Помощь в пике

Вкладка **Помощь в пике** показывает известные пики союзников и врагов. Отдельный игровой пикер **860 × 520** появляется только при свежем GSI `HERO_SELECTION`, даже до выбора своего героя. Он содержит состав 5 × 5 и до пяти рекомендаций с причинами и рисками. Если экран меньше, размер и положение ограничиваются его рабочей областью. Боковая карточка во время пика скрыта и больше не содержит функций выбора героя.

Пикер рассматривает **всех 127 героев**, кроме уже выбранных и запрещённых. Кнопки **1–5** меняют позицию и выборку статистики; выбор сохраняется и синхронизируется между окнами. Предпочтений и авторских бонусов героев нет. При отсутствии сопоставимых данных герой доступен через **Проверить героя**, но не получает выдуманную оценку. Подробные предметы, навыки и игровые советы по прежнему реализованы для пяти профилей керри; каталог пикера от них независим.

На стадии `STRATEGY_TIME` оба окна скрыты. Когда герой появляется на карте (`PRE_GAME`, включая подготовку до выхода крипов, или `GAME_IN_PROGRESS`), показываются боковые советы 340 × 420 либо 340 × 600. В меню, после матча, в наблюдении и после 15 секунд без свежего GSI оба игровых окна скрыты. Пауза в активном матче сохраняет боковую карточку с сообщением о паузе. Настройка **Автоматически показывать оверлеи** разрешает показ на нужной стадии, но не раскрывает окна в меню.

- Нажми пустой слот или портрет, чтобы исправить состав. В отдельном пикере есть страницы по 20 героев и поиск: нажатие в поле явно включает ввод, **Enter**, **Escape**, выбор героя или **Готово** освобождают фокус. Обычные кнопки и портреты фокус не забирают.
- **Ctrl + Alt + L** во время пика открывает выбор состава драфта; во время матча открывает прежний выбор участников линии.
- **Баны** исключают героев из рекомендаций. **Проверить героя** показывает имеющуюся оценку другого кандидата без изменения состава; **К топ-3** возвращает рекомендации. Личные предпочтения пока не используются.
- **Вернуть авто** снимает ручные поправки. Поправка, включая явно очищенную команду, имеет приоритет до нового драфта. Состав передаётся в матч для советов и выбора участников линии.
- Для проверки вне игры нажми **Проверить драфт** в основном окне. Такой просмотр не раскрывает игровые оверлеи; их видимость определяется реальной стадией GSI. Явный деморежим позволяет отдельно проверить боковые советы.
- Если GSI не сообщает твою сторону, укажи Radiant/Dire. Без подтверждённой стороны две команды не назначаются автоматически.

Крестик пикера скрывает его до следующего пика. **Ctrl+Alt+O** скрывает или возвращает окно текущей стадии, **Ctrl+Alt+M** позволяет переместить его. Горячие клавиши не раскрывают оверлей вне нужной стадии. Позиции двух окон сохраняются отдельно, а изменение компактности относится только к боковой карточке. Ручное скрытие одного окна не мешает другому появиться на следующей стадии.

Программа использует необязательные публичные поля `draft.team2/3.pickN_id` и `banN_id`, когда Dota их присылает. Если поля отсутствуют, подтверждённые повторными кадрами верхние портреты дополняют состав. У пика отдельная калибровка крупных портретов, независимая от игрового HUD; на этой стадии передаются только десять небольших областей портретов. В «Анализе экрана» ручная коррекция областей автоматически сохраняется для текущей стадии. Баны по изображению автоматически не распознаются. На предоставленном реальном кадре определились все десять героев при 1080p и после уменьшения до 720p; другие разрешения и оформления могут потребовать коррекции.

Основной источник статистики — STRATZ через тот же защищённый токен, что и сборки. Адаптер проверяет актуальную GraphQL-схему перед запросом. Отдельные выборки позиций 1–5 получают подтверждённый фильтр `positionIds`; работа фильтра проверена в живом API. Винрейты агрегируются по доступным полным последовательным дням, а не только по одному последнему дню. Пары используют нативное поле STRATZ `synergy`, учитывающее силу обоих героев. Фильтры патча и рейтинга не считаются подтверждёнными, если они не были применены к данным.

Резерв — [OpenDota](https://docs.opendota.com/) с каталогом всех 127 героев и наблюдаемыми исходами разобранных матчей. В позиционном резерве роль оценена по линии и распределению фарма, что явно указано в интерфейсе; уверенность ограничена. Матчапы, союзные пары и базовая победность из одной резервной выборки не смешиваются с неподходящими публичными итогами. Источник, дата, область выборки и покрытие показаны в деталях.

Рекомендации сортируются по внутренней статистической оценке полной точности. В интерфейсе показаны место, WR на позиции, причина выбора и риск; внутренний индекс не является вероятностью победы. Вклад каждой известной пары складывается: нейтральные и неизвестные пики не стирают существующий контрпик. Малые выборки сглаживаются; общие пары влияют слабее позиционных. Подробности данных и учтённых пар доступны отдельно. Авторские описания способностей и личные предпочтения не добавляют баллов. Позиции противников на линии не угадываются. Пары могут включать одни и те же матчи; количество игр между ними не суммируется. Неподходящие или слишком старые данные исключаются; дата наблюдений отделена от даты загрузки.

Кеш проверяется раз в сутки, запросы выполняются в фоне вне матча и автоматического пика. Рекомендации пересчитываются локально после изменения состава. Ошибка API сохраняет предыдущий кеш; новый тяжёлый анализатор или постоянные запросы на каждом кадре не добавлены.

## Сборка и навыки

Основной провайдер — **[STRATZ GraphQL API](https://stratz.com/api)**. В настройках сохрани персональный API-токен STRATZ и проверь соединение. Токен хранится отдельно в `runtime/stratz-credentials.json`, не возвращается интерфейсу и не включается в сведения о состоянии. Он нужен только для авторизованных запросов к STRATZ.

Автообновление проверяет кеш при запуске и обновляет его вне активного матча, когда прошло шесть часов. Его можно отключить в настройках. Нет токена, API вернул ошибку или данные не прошли проверку — предыдущий пригодный кеш сохраняется. Само наличие выбранного STRATZ не означает, что приложение уже получило его данные: интерфейс отдельно показывает основной и фактически используемый источник.

Без токена используется локальный резерв **OpenDota**. В комплекте — 15 разобранных carry-матчей [OpenDota](https://docs.opendota.com/) с 29 августа по 11 октября 2026 года и восемь маршрутов. Подтверждён базовый патч 7.41, принадлежность к 7.41f не подтверждена. Покупки и навыки каждого маршрута взяты из одного матча; тайминги не являются обязательными дедлайнами. Личный импорт имеет приоритет до возврата к наблюдаемым сборкам.

Перед использованием рекомендаций смотри фактический источник, дату обновления, патч и размер выборки. После патча старая выборка не становится новой автоматически; небольшой объём свежих матчей не гарантирует лучший билд. Запросы STRATZ требуют проверки реальным личным токеном: без него успешное получение живой выборки не подтверждено.

Во вкладке **Билд и навыки** показывается записанный порядок улучшений выбранного героя. Обозначение `№… · ≥…` — номер улучшения и реконструированный минимально допустимый уровень героя: точные уровни источник не сообщает, игрок мог сохранять очки. Неизвестные улучшения не подменяются. Врождённые и предметные навыки не предлагаются для обычной прокачки. Следующий навык требует совместимых способностей и уровней GSI.

Ручное обновление запускается вне матча. Для STRATZ нужен сохранённый токен; резерв OpenDota не обновляется по сети автоматически без явного запроса. [Каталог Valve](https://www.dota2.com/datafeed/herodata?language=english&hero_id=42) используется для проверки навыков. При личном импорте он остаётся активным до **Вернуть автоматические билды**.

Кнопка D2PT открывает [carry-сборку WK](https://dota2protracker.com/builds/wraith-king-pos1-1) для просмотра. Прямой выгрузки нет: [условия сайта](https://dota2protracker.com/terms-of-service) запрещают автоматический сбор и применение данных в приложении. Документированный публичный API с разрешением такого использования не найден. OpenDota не выдаётся за данные D2PT или гарантированно лучший билд текущего патча.

### Личный JSON

Вне матча выбери **Билд и навыки → Загрузить сборку**. Отредактируй копию `data/personal-build-template.json`; в переносимой версии — `resources/app/data/personal-build-template.json`. Это пример личного плана.

- Сохрани `kind: "personal"`, `heroId: 42`, `build.role: "carry"`.
- Предмет: `{"key":"radiance","phase":"mid"}`. Фазы: `start`, `early`, `mid`, `late`, `situational`; необязательный `targetMinutes` — твой ориентир.
- Навык: `{"heroLevel":2,"abilityKey":"skeleton_king_bone_guard"}`. Уровни уникальны; неизвестные способности, врождённые навыки и недоступные ранги отклоняются. Ключи талантов есть в шаблоне.

Импорт сохраняется в `runtime/custom-build.json`; ошибка не заменяет предыдущий. **Вернуть автоматические билды** оставляет резервный файл. Также принимается явно разрешённый владельцем данных экспорт D2PT; сохранение обычной страницы разрешением не считается.

## Нагрузка и управление

Обрабатываются редкие кадры одного окна Dota. **Экономный** — интервал от 5 секунд, **Быстрее** — от 2,5 секунд, **Только GSI** — без захвата. Фоновый захват работает, когда виден игровой пикер или боковая карточка; скрытый боковой оверлей не мешает распознаванию во время пика. Если оба окна скрыты, захват приостанавливается. Открытая проверка HUD — явное исключение, доступное и без GSI. Поток ограничен 1 FPS и 1280 × 720; в обработчик передаются только маленькие вырезки HUD, миникарты и найденных значков, максимум 22 области. Частота зависит от планировщика и обработки. Влияние на FPS Dota ещё требует замера.

Оверлей имеет компактный размер 340 × 420 px или расширенный 340 × 600 px. Иконки состава занимают один небольшой ряд. Оценка темпа использует GSI и не запускает дополнительный захват или модель на видеокарте.

| Клавиши | Действие |
|---|---|
| Ctrl + Alt + W | Настройки |
| Ctrl + Alt + O | Показать / скрыть оверлей |
| Ctrl + Alt + M | Перемещение / пропуск кликов |
| Ctrl + Alt + L | Выбор состава в оверлее / закрыть выбор |
| Ctrl + Alt + C | Компактный вид |
| Ctrl + Alt + Q | Выход |

Закрытие настроек оставляет приложение в трее. Кадры обрабатываются локально в памяти. GSI слушает `127.0.0.1:43829` и проверяет токен; настройки лежат в `runtime/settings.json`. Инъекций, чтения памяти игры и автоматических действий героя нет.

## Данные и проверка

В пикере можно выбрать рейтинг; при отсутствии нужного кеша нажми «Обновить данные» в основном окне. Если уже загружается другая группа, запрос попадёт в очередь. Пять рекомендаций показывают WR на позиции, причину выбора и риск против конкретного состава. Вместо условных баллов отображаются место в списке и краткая оценка матчапа. Подробности данных доступны отдельно: база WR и пары имеют независимые периоды и фильтры. Период пар проверяется через API; точная дата последнего учтённого матча остаётся неизвестной. Подробная проверка: [PICKER-VALIDATION-0.9.3.md](PICKER-VALIDATION-0.9.3.md). `npm run draft:sensitivity` сравнивает 74 состава при четырёх весах матчапов без изменения рабочей формулы. Подготовка исторической проверки описана в [DRAFT-EVALUATION.md](DRAFT-EVALUATION.md).

`src/product.cjs` содержит название, роль и пять реализованных carry-профилей. Для каждого из четырёх новых героев включено по 12 разобранных carry-матчей OpenDota с покупками и навыками из тех же матчей, отдельный каталог Valve и личный шаблон JSON. У резервной выборки подтверждён базовый патч 7.41; актуальная буква патча не подтверждена. Регистрация будущего героя требует его данных, анализа и проверки.

`data/d2pt-wraith-king.json` — историческое имя резервного кеша **OpenDota**, не выгрузка D2PT. Происхождение и IDs матчей сохранены внутри. `data/wraith-king.json` содержит агрегированные покупки и справочники; `data/sources/wk-live-abilities.json` — текущий каталог Valve. Иконки — Valve CDN; атрибуция проверочных примеров [Dota2-Vis](https://github.com/RicardoRCarvalho/dota2-vis) сохранена в `data/assets/dota2-vis-test/README.md`.

`Update-Data.cmd` обновляет базовые справочники и изображения; STRATZ-сборки обновляются в приложении. Исходникам нужен Node.js 22+; переносимая версия содержит Electron.

```powershell
npm test
node_modules/electron/dist/electron.exe . --smoke-test
node_modules/electron/dist/electron.exe test/vision-fixtures.cjs
node scripts/update-d2pt.cjs
```

Точность зависит от HUD, масштаба и перекрытий. Сходство с шаблоном не является вероятностью правильного ответа. Предметы врагов, криповые волны и скрытые позиции не распознаются. Правила механик требуют пересмотра после патчей.
