# Core Coach 0.6.0

Состав линии выбирается из известных команд: нажми карточку участника либо «Выбрать состав» и отметь напарника, затем двух противников. Основной выбор показывает только соответствующие портреты команды; полный каталог доступен для исправления неполного драфта. Нельзя назначить одного врага дважды. Ручной выбор имеет приоритет и отмечается галочкой в оверлее. Возврат к автоматике сохраняет известные команды. Оверлей продолжает пропускать клики.

Поддерживаются Wraith King, Juggernaut, Sven, Phantom Assassin и Luna. GSI автоматически выбирает профиль в активном матче; вне матча есть переключатель для просмотра и деморежима. Покупки, прокачка и советы используют способности выбранного героя. Пассивные ультимейты не предлагаются как активный каст. Старый анализ сцены и автоопределение участников WK сохранены; для остальных четырёх участников выбирай вручную.

Для каждого нового героя включены 12 настоящих carry-матчей OpenDota, покупки и прокачка из одного и того же матча, каталог способностей Valve, личный шаблон сборки и иконки предметов. STRATZ остаётся основным провайдером; его запросы теперь учитывают выбранного героя. Без токена используется честно отмеченный резерв OpenDota. Базовый патч резерва — 7.41; буква текущего патча не подтверждена.

Кеши STRATZ, резервные данные и личные сборки разделены по герою. Токен STRATZ остаётся в защищённом общем хранилище. При переключении профиля прежняя личная статистика и состав линии не переносятся. Распознанные портреты остальных керри помогают ручному выбору команд и не назначают роли автоматически.

Без GSI выбранный вручную матчап даёт условные советы, но не выдумывает здоровье, предметы, свободные очки или перезарядки. Публичный порядок навыков доступен для просмотра, следующий навык требует собственного состояния героя. Распознавание не получает новую тяжёлую модель; изображения героев повторно не декодируются при смене профиля.
