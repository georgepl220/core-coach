# Core Coach 0.7.0

Добавлена помощь в пике для Wraith King, Juggernaut, Sven, Phantom Assassin и Luna. Оверлей автоматически переключается по свежей стадии GSI до выбора собственного героя и возвращается к прежнему виду перед началом матча.

Известный состав, баны, статистика противников, союзные способности и комфортные герои определяют топ-3. Каждая карточка показывает причины, риски, уверенность и оценку пригодности 0–100. После выбора собственного героя первая карточка оценивает этот выбор. Баллы не обозначают шанс победы.

Состав можно исправить из обоих окон. Поиск доступен в приложении, страницы портретов — в оверлее. Ctrl+Alt+L открывает редактор текущей стадии. Данные пика передаются в матч; старое автоопределение и ручной выбор участников линии сохранены.

STRATZ остаётся основным провайдером, токен хранится в существующем защищённом хранилище. Запросы проверяют GraphQL-схему, неподтверждённые фильтры не заявляются. Живое подключение этого нового адаптера требует персонального токена и пока не проверено.

В комплекте — реальные годовые матчапы OpenDota пяти керри, полученные 13 октября 2026 года. У резерва нет фильтров по патчу/рангу/роли и статистики синергий; ограничения видны в интерфейсе. Ежедневное обновление выполняется в фоне; матч использует локальный кеш.

Клики принимает только редактор состава и его кнопки. Остальная область оверлея пропускает мышь, фокус остаётся у игры. Размер во время пика — 380×600, обычный размер — 340×420 либо 340×600.

Проверки включают неполный драфт без своего героя, выбранного керри, баны, сохранение состава, новый матч, отсутствие токена, ошибки API, переключение размера, ограничение области кликов и возврат к обычным советам. Реальный экран пика Dota разных режимов/масштабов потребует отдельной проверки; ручная поправка остаётся доступна.
