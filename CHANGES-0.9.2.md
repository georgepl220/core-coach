# Core Coach 0.9.2

- Раздельная проверка свежести и контекста базового WR и пар героев.
- Фильтр рейтинга STRATZ с отдельными кешами; общий кеш не подменяет выбранный рейтинг.
- Патч базы выводится только из проверенного полного дневного периода внутри версии каталога STRATZ. Неизвестный патч пар не подставляется.
- Полная точность сортировки; округление только в интерфейсе.
- Полнота данных и отдельные периоды базы/пар для каждого героя; близкие баллы не выдаются за доказанное превосходство.
- Сравнение топ-5 на четырёх составах при 0,5× / 1× / 2× / 3× веса врагов. Рабочие коэффициенты сохранены.
- Сжатые неизменяемые публичные снимки для будущей проверки и защита от использования будущих/неподтверждённых периодов.

Подробности и ограничения: `PICKER-VALIDATION-0.9.2.md`. Сравнение чувствительности не является доказательством роста точности.
